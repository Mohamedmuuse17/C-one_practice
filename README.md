

**Chapter 1: Introduction**
- **Object** = data (**Property**) + actions (**Method**). **Control** = visible object (Button, Label, TextBox).
- **Visual Studio:** Designer (layout), Solution Explorer (files), Properties (values), Toolbox (controls).
- **Project** = one application. **Solution** = container for one or more projects.
- **Event handler** = method that runs when the user does something (e.g., click).
- **Code structure:** Namespace ⊃ Class ⊃ Method.
- Key items: `MessageBox.Show()`, `this.Close()`, `//` comments.

**Chapter 2: Processing Data**

| Topic | Summary |
|---|---|
| Data types | `string` (text), `int` (whole number), `double` (fractional), `decimal` (money, needs `m`) |
| Variables | Declare and assign before use. Local = one method only. Field = whole class |
| Constants | `const double RATE = 0.129;` |
| Casting | `(int)x` |
